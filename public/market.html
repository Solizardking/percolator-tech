Trade (devnet app)

Launch the trading app → trade.percolator.tech (devnet).

The trading UI is the React + Vite app in clawd-market/app — it builds every transaction in the browser and the user's wallet signs; the server holds no keys. It runs locally today (npm install && npm run build && npm start in app/); hosting it on percolator.tech is the merge-step decision in docs/INTEGRATION.md. The Clawd Chain testnet app stays at /trade.
