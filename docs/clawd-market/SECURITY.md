# Security policy

**Status: unaudited, devnet only.** Do not deploy to mainnet or deposit real funds until every item in
[docs/MAINNET-CHECKLIST.md](docs/MAINNET-CHECKLIST.md) is done.

Report vulnerabilities privately via GitHub Security Advisories on this repository
(`Security` tab -> `Report a vulnerability`). Please do not open public issues for security bugs.

In scope: `program/` (on-chain program), `engine/` (risk engine), `client/` (transaction builders).
The program embeds a `security.txt` (solana-security-txt) pointing here.

Upstream issues in aeyakovenko/percolator-prog or aeyakovenko/percolator should also be reported upstream.
